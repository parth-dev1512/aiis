# Ashoka Impact Investing Society – Website

Website for the Ashoka Impact Investing Society (AIIS), a student-led body at Ashoka University working at the intersection of finance and social impact.

The site introduces the society's mission, its "Impact Capital" evaluation methodology, portfolio and research, and invites students to join.

## Pages

- `index.html` – landing page: mission, key numbers and calls to action
- `about.html` – story, mission and vision, methodology and governance

## Tech

Static HTML and CSS, no build step. Open `index.html` in a browser or serve the folder:

```bash
npx serve .
```
